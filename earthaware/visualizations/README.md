# 📊 Visualizations

Charts, plots, and diagrams generated from training runs and evaluations.

| File | Description |
|------|-------------|
| `training_loss_curve.png` | Train/val loss vs epoch (generated by the training script) |
| `metrics_dashboard.png` | Combined dashboard: loss curves, NDVI error, EO keyword usage |
| `architecture_diagram.png` | Visual model & platform architecture diagram |
| `architecture_diagram.md` | Mermaid source for the architecture diagram |

Regenerate after each training run:
```bash
python generate_visualizations.py
```
