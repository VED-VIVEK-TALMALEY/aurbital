# 🌍 Aurbital — Multimodal AI for Earth Observation + World-State Research Engine

**Aurbital** (formerly EarthAware / TerraSight) combines:

1. **TerraSight (applied layer)** — an end-to-end geospatial AI platform: a **Multispectral Vision-Language Model** (SpectralViT + GPT-2 + LoRA) with an interactive **3D map research assistant**. Built as a solution to ISRO's challenge of enhancing open-source GPT models with multimodal vision capabilities for Earth Observation (EO) data.
2. **ORBITAL (research layer)** — a **World-State Intelligence & Simulation Engine**: a physics-informed, ensemble world model that supports prediction, counterfactual simulation (`do`-operator), calibrated uncertainty, and active perception — with every claim backed by a committed, re-runnable experiment. See [`orbital/README.md`](orbital/README.md).

> _"Ask questions about satellite imagery in natural language and get intelligent, domain-aware answers — then ask what happens next, what if, and how sure are we."_

LIVE DEMO: https://aurbital.streamlit.app/

## 🚀 Quick Start

### Prerequisites
- Python 3.10+ · Node.js 18+ · NVIDIA GPU with CUDA 11.8+ (8GB+ VRAM recommended)

```bash
git clone https://github.com/VED-VIVEK-TALMALEY/aurbital.git
cd aurbital/earthaware

python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

python verify_setup.py            # verify environment
python train_isro_eo_enhanced.py --epochs 2 --batch-size 1 --grad-accum 4 --lr 2e-5
python -m uvicorn api_server:app --host 0.0.0.0 --port 8000   # model API
```

### Web App

```bash
# Terminal 1 — Node backend
cd earthaware/geo-research-assistant/backend && npm install && npm run dev
# Terminal 2 — React frontend
cd earthaware/geo-research-assistant/frontend && npm install && npm run dev
# Open http://localhost:5173
```
